# کیت برند Your AI Side — نسخهٔ ۱٫۰

مرجع کامل برند در این ریپوی وب‌سایت، زیر پوشهٔ `brand/` نگه داشته می‌شود تا با
اسناد اصلی پروژه (مثل `README.md` و `AGENTS.md` ریشه) قاطی نشود.

## استفاده با Claude Code / Cursor / Codex

برای کار روی UI بگو:
«ظاهر را بر اساس `brand/` بساز؛ `BRAND.md` و `FOR-AGENTS.md` را کامل بخوان
و از `tokens/brand.css` و فایل‌های `logo/` استفاده کن.»

| مخاطب | شروع از |
|---|---|
| انسان (EN) | `BRAND.md` / `README.md` |
| انسان (FA) | همین فایل |
| ایجنت کدنویس | `FOR-AGENTS.md` |

## نقشهٔ پوشه

- `BRAND.md` — مشخصات کامل برند (مرجع اصلی، انگلیسی)
- `FOR-AGENTS.md` — دستورالعمل اجرایی ایجنت‌های کدنویس
- `logo/` — مارک، وردمارک، لاک‌آپ‌ها — دو تم
- `icons/` — آیکون اپ + فاوآیکون
- `tokens/` — توکن‌های رنگ/تایپ/شعاع در CSS و JSON
- `fonts/` — منابع فونت‌ها (لاتین + فارسی)
- `examples/hero.html` — نمونهٔ مرجع هیرو در هر دو تم

کپی‌های وب در `public/brand/` و آیکون‌های اپ در `src/app/` هستند؛ منبع حقیقت
همیشه همین پوشهٔ `brand/` است.

## خلاصهٔ تصمیم‌های نهایی

مارک: «دو نیمه» فشرده و صعودی (نارنجی بالا-راست)، درز ۸ واحدی مقدس.
رنگ: سیستم light-first — استخوانی #F4F2EC / کربن #141414، اکسنت سیگنال
#F04E23 (تیره: #FF6A42). یک اکسنت، بدون گرادیان.
وردمارک: youraiside یک‌کلمه با ai نارنجی، Inter Tight Bold با تراکینگ −0.035em.
تگ‌لاین: Put AI on your side. — نقطهٔ پایانی همیشه نارنجی.
